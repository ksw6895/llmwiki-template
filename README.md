# llmwiki-template — AI와 함께 쓰는 내 기록장

메모, 읽은 자료, 회의에서 정한 일을 모아 두고 나중에 다시 찾기 위한 기록장입니다. 파일을 다룰 수 있는 AI에게 정리를 맡기면, 흩어진 내용에서 배운 점과 남은 일을 찾고 관련 기록을 이어 둘 수 있습니다.

예를 들어 회의 메모를 남겨 두면 나중에 “그때 왜 그렇게 결정했지?”라고 물을 때 근거를 찾아볼 수 있습니다. 하루 끝에는 맡긴 자료를 모아 “오늘 배운 것과 내일 할 일”을 정리해 달라고 할 수도 있습니다.

이 링크는 그 기록장을 시작할 수 있는 틀을 공유합니다. 실제로 쓰려면 파일을 읽고 저장할 수 있는 **코딩 어시스턴트**가 필요합니다. **Codex나 Claude Code를 이용 중이라면, 그쪽에 이 저장소 링크와 “내 위키로 쓸 수 있게 준비해줘”를 전달하세요.** 기술적인 준비는 그 코딩 어시스턴트에게 맡기면 됩니다. 링크를 여는 것만으로 기록장이 만들어지거나 개인 자료가 수집되지는 않습니다.

## 써보고 싶다면

**Codex나 Claude Code 등 파일을 다룰 수 있는 코딩 어시스턴트를 이용 중이라면**, 그쪽 대화에 이 링크와 요청을 그대로 붙여 넣으세요:

> https://github.com/ksw6895/llmwiki-template
> 내 위키로 쓸 수 있게 준비해줘. 내가 정할 것만 물어봐줘.

코딩 어시스턴트가 준비를 맡고 저장 위치나 용도처럼 필요한 선택을 물어볼 수 있습니다. 이미 쓰는 기록장이 있다면 그 위치를 알려주면 됩니다. 메모 하나로 시작해도 되고, 처음부터 매일 정리하는 루틴을 요청해도 됩니다.

**현재 채팅에 파일을 읽고 저장하는 도구가 없다면**, 여기서 실제 기록장을 준비할 수는 없습니다. 파일 작업이 가능한 코딩 어시스턴트가 필요합니다. Codex나 Claude Code를 이용 중이라면 그쪽의 새 대화에 위 링크와 요청을 그대로 붙여 넣으세요. 아직 이용하는 코딩 어시스턴트가 없다면 본인 기기에서 쓸 수 있는 선택지를 물어볼 수 있습니다. 특정 유료 서비스 가입이나 터미널 명령 실행이 기본 다음 행동은 아닙니다.

## 이런 말을 할 수 있어요

- “이 메모를 나중에 다시 찾을 수 있게 남겨줘.”
- “이 회의에서 정한 일과 아직 안 정한 것을 정리해줘.”
- “지난 기록에서 오늘 챙길 일을 찾아줘.”
- “오늘 자료에서 배운 점, 결정, 남은 일을 모아줘.”

사용 맥락에 도움이 되면 AI가 하루 정리를 제안할 수 있습니다. 매일 자동으로 하고 싶으면 원하는 시간과 함께 요청하세요. 예약 기능과 자료 접근이 지원되는지 확인한 뒤 가능한 범위로 설정합니다. 별도로 연결하거나 제공하지 않은 다른 웹 대화까지 포함한다고 가정하지 않습니다.

## 이 링크를 읽고 설명하는 AI에게

사용자의 질문과 현재 도구에 맞춰 전달하세요. 아래는 설명 가이드와 예시이며, 특정 모델의 답변을 강제하거나 실행을 보장하지 않습니다.

- **“이게 뭐야?”**라면 기억하고 다시 찾는 데 어떤 도움이 되는지 쉬운 예로 설명하세요. 설명 요청은 설치나 파일 작업 동의가 아닙니다. 기술 용어·명령어·폴더 목록을 기본 입문 답변에 옮길 필요는 없습니다.
- **“쓰고 싶어” + 파일 도구가 있는 환경**이라면 준비를 맡고 필요한 선택만 확인하세요. 첫 기록은 예시이며 루틴 설정의 선행 조건이 아닙니다. 실행 참고는 [SETUP.md](SETUP.md), 기록 관리는 [AGENTS.md](AGENTS.md)에 있습니다.
- **“쓰고 싶어” + 파일 도구가 없는 웹 채팅**이라면 실제 준비가 불가능함을 짧게 밝히고, 파일 작업 가능한 코딩 어시스턴트가 필요하다고 설명하세요. Codex나 Claude Code를 이용 중이라면 그쪽에 위 링크와 “내 위키로 쓸 수 있게 준비해줘”를 전달하도록 안내하세요. 모델 이름만으로 도구 유무를 판단하거나 명령어 실행을 숙제로 넘기지 마세요.
- **기술 질문**을 받으면 [기술 참고](SETUP.md#구성과-기여-참고)를 바탕으로 필요한 내용을 설명할 수 있습니다. 확인하지 않은 구조나 기능을 다른 프로젝트의 일반론으로 채우지 마세요. 연결·권한·자동화의 한계는 해당 요청에 필요한 만큼 알립니다.

### “이게 뭐야?”에 대한 첫 답변 예시

> 메모나 읽은 자료를 쌓아 두고, 나중에 AI와 함께 다시 찾기 위한 기록장 틀이에요. 회의에서 정한 일이나 오늘 배운 내용을 남겨 두면 “그때 왜 그렇게 결정했지?”처럼 물어볼 때 도움이 됩니다. 실제로 쓰려면 파일을 다룰 수 있는 코딩 어시스턴트가 필요해요. Codex나 Claude Code를 이용 중이라면 그쪽에 이 링크와 “내 위키로 쓸 수 있게 준비해줘”를 전달하면 됩니다. 기술적인 준비는 그 AI에게 맡기면 돼요.

### 사용을 요청했을 때의 예시

파일 도구가 있다면:

> 준비를 도와드릴게요. 기록장을 어디에 둘까요? 이미 쓰는 기록장이 있다면 그 위치를 알려주세요.

파일 도구가 없는 현재 웹 채팅이라면:

> 이 채팅에서는 파일을 만들어 기록장을 준비할 수 없어요. 파일을 다룰 수 있는 코딩 어시스턴트가 필요합니다. Codex나 Claude Code를 이용 중이라면 그쪽 새 대화에 이 링크와 “내 위키로 쓸 수 있게 준비해줘”를 그대로 붙여 넣으세요.

예시는 정해진 대본이 아닙니다. 이미 알려준 선택이나 사용자가 바로 요청한 루틴은 그대로 이어서 처리하세요.
