## 대상 위키

이 문서가 들어 있는 vault 루트의 `AGENTS.md`와 필요한 사용자 선호를 참고합니다. 전역 진입점으로 호출했다면 그 진입점에 명시된 vault 경로를 사용합니다. cwd나 접근 가능한 전체 자료가 곧 대상 범위라고 가정하지 않습니다.

요청 범위의 깨진 링크, 중복 후보, 오래 미처리된 메모, 실제 필요한 메타데이터 누락 등을 찾아 보고합니다. 날짜 기준은 사용자 선호와 자료의 성격에 맞춥니다. 기존 출력 형식이나 템플릿을 모든 파일에 강제하지 않고, 문서·템플릿의 예시 링크는 실제 노트 링크와 구분합니다.

근거 파일과 수정 제안을 알립니다. 점검 요청은 기본으로 읽기 작업이며, 사용자가 수정을 요청한 범위에만 변경을 적용합니다. 기존 `--fix <category>` 입력도 해당 범주의 수정 요청으로 해석할 수 있습니다. 실제 변경이 있으면 `log.md`에 기록합니다.
