## 대상 위키

이 문서가 들어 있는 vault 루트의 `AGENTS.md`와 필요한 사용자 선호를 참고합니다. 전역 진입점으로 호출했다면 그 진입점에 명시된 vault 경로를 사용합니다. cwd나 접근 가능한 전체 자료가 곧 대상 범위라고 가정하지 않습니다.

처음 설명은 [README.md](../README.md)의 효용과 예시를 참고하며 설치·파일 작업으로 확대하지 않습니다. 사용 요청과 파일 도구가 있으면 [SETUP.md](../SETUP.md)를 참고해 에이전트가 준비를 맡고 필요한 선택만 확인합니다. 파일 도구가 없는 채팅에서는 실제 준비가 불가능함을 밝히고 링크와 요청을 파일 작업 가능한 환경으로 전달하는 다음 행동을 안내합니다.

사람이 문서를 읽고 링크와 연결을 살펴볼 도구로 Obsidian을 기본 권장합니다. 설치와 설정을 요청하면 에이전트가 맡고, 기존 앱이나 다른 도구 선호는 존중합니다. 백업과 Sync는 별도 선택이며, GitHub 백업을 선택하면 본인 계정의 개인 비공개 저장소를 기본으로 안내합니다.

프로필 수집·전역 명령 설치·앱 설치를 시작 조건으로 삼지 않습니다. `scripts/setup.sh`의 기본 실행은 검증과 안내만 하며, 쓰기·설치 옵션은 사용자가 선택했을 때 사용합니다. 메모 하나를 정리하는 것은 첫 사용의 한 예입니다. 처음부터 루틴 설정을 요청했다면 첫 기록을 요구하지 않고 그 목적을 바로 처리합니다.
