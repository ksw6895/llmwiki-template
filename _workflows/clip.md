## 대상 위키

이 문서가 들어 있는 vault 루트의 `AGENTS.md`와 필요한 사용자 선호를 참고합니다. 전역 진입점으로 호출했다면 그 진입점에 명시된 vault 경로를 사용합니다. cwd나 접근 가능한 전체 자료가 곧 대상 범위라고 가정하지 않습니다.

입력은 URL, 텍스트 또는 사용자가 지정한 파일입니다. 사용 가능한 웹 읽기 도구로 URL 본문을 확인할 수 없으면 실패/제한을 알리고, 필요한 경우 텍스트 제공을 요청합니다. 제목·저자·게시일은 확인된 값만 사용합니다.

자료의 핵심과 사용자 맥락에 유용한 부분을 요약하고, `05-Resources/`나 `00-Inbox/`, 관련 프로젝트에 저장합니다. `10-Templates/tmpl-clip.md`는 선택 참고입니다. 원문 전체를 기본으로 복제하지 않고 출처와 필요한 짧은 인용을 남깁니다. 사용자가 원본 보존을 원하면 허용된 원본을 별도 파일로 저장합니다.

실제 관련 기록이 있으면 연결하고 기존 MOC를 갱신할 수 있습니다. 빈 링크나 새 MOC를 형식상 만들지 않습니다. 저장 파일과 요약을 보여주고 `log.md`에 기록합니다.
