# Wiki

이 스킬이 들어 있는 저장소가 대상 vault입니다. 호출 위치가 다르면 스킬의 실제 파일 위치 또는 명시된 vault 경로를 기준으로 찾고, 대상이 여러 개면 사용자의 선택을 확인하세요.

vault 루트의 `AGENTS.md`가 공통 지침입니다. 처음 사용에는 `SETUP.md`, 하루 자료 정리에는 `_workflows/daily-review.md`를 참고하세요. 다른 작업은 필요한 `_workflows/<name>.md`만 읽으면 됩니다. 스킬의 실제 위치에서 루트는 `../../..`입니다.

자연어로 요청받은 목적을 처리합니다. 워크플로는 참고 예제이며 명령어 호출이나 전체 설정 완료를 요구하지 않습니다. 소스 접근·설치·예약은 사용자 요청 범위와 현재 실행 환경을 따릅니다. 스킬이 선택되었다고 setup 스크립트를 실행하지 마세요.
